# Rig plan V01

This is a hybrid 2.5D mesh rig, not a set of rigid Photoshop transforms.

- One high-resolution character texture is warped by a weighted mesh.
- Bones control local regions with spring lag.
- Eyes/pupils can be separate overlays.
- Large limb rotations are prohibited until hidden anatomy is generated.
- The lantern freezes spring motion and collapses z-depth/shadow to the paper plane.
