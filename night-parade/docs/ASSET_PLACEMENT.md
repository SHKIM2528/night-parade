# Asset placement

```text
source/green_monkey_source_context.png
  -> public/art/characters/green-monkey/source/

clean_plate/green_monkey_clean_plate.png
  -> public/art/clean-plates/

cutouts/*.png
  -> public/art/characters/green-monkey/cutouts/

masks/*.png
  -> public/art/characters/green-monkey/masks/

manifest.json
  -> public/art/characters/green-monkey/rig/
```
